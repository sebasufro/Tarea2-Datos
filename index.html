📋 Configuración del modelo Teachable Machine

PASO 1 · ENTRENAR
Ve a teachablemachine.withgoogle.com → Nuevo proyecto → Imagen estándar. Crea 4 clases: arriba · derecha · izquierda · neutral. Graba ~50 fotos por clase con tu cámara.
PASO 2 · EXPORTAR
Clic en Exportar modelo → pestaña Tensorflow.js → Subir modelo. Copia la URL que termina en /model.json.
PASO 3 · CONFIGURAR
Abre js/controls.js y reemplaza YOUR_MODEL_ID en la variable MODEL_URL con la URL de tu modelo exportado.
PASO 4 · JUGAR
Abre index.html con un servidor local (VSCode Live Server, o python -m http.server). Acepta el permiso de cámara. ¡A jugar! 🎮
Solo P5.js + ML5.js · Sin otros frameworks · Modo demo con teclado disponible sin modelo
